# Produktrecherche – E-Commerce Start

Stand: 2026-09-20

## Ziel
Ein erstes Produkt finden, das mit kleinem Budget testbar ist. Noch kein Produkt ist freigegeben und es wird nichts gekauft.

## Erste Kandidaten zur Prüfung
1. Kofferraum-Organizer
2. Schubladen-Organizer / Trenner
3. Hunde-Reisezubehör
4. Kabel-Organizer

## Warum diese Kandidaten?
- verständlicher Nutzen
- grundsätzlich einfache Produktkategorien
- keine notwendige Elektronik für die ersten Tests
- potenziell als Bundle verkaufbar
- kleine bis mittlere Produkte möglich

## Aktuelle Markt-Verkaufspreise
Die folgenden Preise sind nur beobachtete Endkundenpreise aus aktuellen Produktsuchen. Sie sind NICHT unsere Einkaufspreise:
- Kofferraum-Organizer: mehrere Angebote ca. 10–40 EUR
- Schubladen-Organizer: mehrere Angebote ca. 15–33 EUR
- Hunde-Reiseprodukte: mehrere Angebote ca. 9–40+ EUR
- hochwertige Hunde-Reiseprodukte können deutlich höher liegen

## Noch zu prüfen
Für jeden Kandidaten:
- echter Lieferant
- Einkaufspreis
- Versandkosten
- Lieferzeit
- Mindestbestellmenge
- EU/DE-Versand
- Retourenbedingungen
- Produktkonformität / Kennzeichnung
- Verpackung
- Zahlungs-/Marktplatzgebühren
- realistische Werbekosten
- Deckungsbeitrag
- Wettbewerbsdichte
- Differenzierung
- Kapitalbedarf

## Kostenregel
Keine Bestellung, Domain, Werbung oder kostenpflichtige API ohne ausdrückliche Freigabe.

## Import-Hinweis
Seit 01.07.2026 gilt für E-Commerce-Sendungen aus Nicht-EU-Ländern eine neue pauschale Einfuhrabgabe von 3 EUR für Sendungen unter 150 EUR; weitere Abgaben können hinzukommen. Deshalb werden EU-/DE-Lieferquellen besonders geprüft.

## Nächster Quality Gate
Noch keine Produktentscheidung. Zuerst reale Lieferanten und vollständige Stückkosten für die Kandidaten ermitteln.
